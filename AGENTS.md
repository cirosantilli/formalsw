See code and README guidelines under `=== Coding guidelines` of `README.adoc`.

The README.adoc is meant to be read by humans. It is not an arbitrary dump of your technical knowledge about this repo. Statements have to be somewhat concise and understandable and digestible by humans. Avoid humongously long paragraphs or excessive internals details or extremely long lists of TODOs. People want to know how to get things done, they don't care about the internals so much, unless it helps see a global feature or important limitations.
